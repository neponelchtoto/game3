


## Описание проекта
**Название**: Rabbit

**Цель**: ознакомиться с основами разработки программного обеспечения через проектирование, реализацию и тестирование приложения для игры с кроликом, который должен набрать за установленное время как можно больше наград-"морковок" и не попасться на врага-"каплю".

**Мотивация**: изучение инструментов и средств разработки программного обеспечения посредством проектирования, реализации и тестирования приложения.

## Перечень функциональностей проекта
Проект является игрой, поэтому подразумевается одна категория пользователей - игроки.
1. Приложение должно создавать фон игры, границы, персонажа и игровые объекты: награду-морковки, врагов-капли и результаты;
2. Пользователь должен иметь возможность видеть все свои удачные попытки и количество "морковок", которое он успел собрать за установленное время;
2. Пользователь должен иметь возможность перемещать персонажа в пределах поля, не проходя сквозь стены;
4. Пользователь должен иметь возможность выиграть - за установленное время собрать как можно больше "морковок" и не попасться на "капли";
5. Пользователь должен иметь возможность проиграть - собрать "каплю";
6. Приложение должно рандомно распределять по полю игры "морковки" и "капли";
6. Пользователь должен иметь возможность закрыть приложение.

## Функциональные модели проекта
### Сценарии использования
1. Пользователь запускает приложение - приложение генерирует поле игры, игрока, "морковки" и "капли";
2. Пользователь нажимает клавишу движения(`wasd`) - приложение проверяет столкновение с границами, "морковкой" или "каплей":
  - пользователь ни с чем не сталкивается - приложение перемещает персонажа;
  - пользователь сталкивается со стеной - приложение ограничивает перемещение в данном направлении;
	- пользователь сталкивается с наградой-"морковкой" - приложение добавляет +1 к счётчику наград за текущую игру;
	- пользователь сталкивается с врагом-"каплей" - приложение выводит сообщение о поражении;
  - пользователь не сталкивается с врагом-"каплей" установленное количество секунд - приложение выводит сообщение о победе и последние результаты игр;
3. Пользователь нажимает на кнопку закрытия - приложение закрывается
